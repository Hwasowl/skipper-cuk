# 세션 재사용 + 반복 루프 설계

날짜: 2026-06-08
대상: 가톨릭대 사이버캠퍼스 강의 자동 시청 매크로 (skipper-cuk)

## 배경 / 문제

현재 흐름은 1회성이다.

1. `chromium.launch()` + `browser.newContext()` 로 **익명 컨텍스트** 생성
2. 사용자가 직접 로그인 → Enter
3. `collectLectures` → 미완료 강의 `for` 루프 1회 시청 → 요약 → 종료

이로 인한 두 가지 불편:

- **세션 휘발**: 익명 컨텍스트라 쿠키가 디스크에 남지 않는다. 프로그램을 끄면 로그인이 사라져, 다시 실행할 때마다 로그인·인증을 반복해야 한다.
- **1회성 실행**: 한 배치(주차)를 다 보면 프로그램이 종료된다. 다른 주차를 보려면 프로그램을 재실행 → 다시 로그인.

## 목표

두 기능을 함께 적용한다. 서로 보완 관계다.

- **A. 세션 영속화**: 브라우저/프로그램을 껐다 켜도 로그인 상태 유지 (재인증 불필요)
- **B. 반복 루프**: 프로그램을 안 끈 채, 다음 주차로 이동 후 Enter만 누르면 같은 브라우저로 계속 시청

## 설계

### 기능 A — 세션 영속화

`launchPersistentContext` 로 전환한다. 사용자 데이터 디렉토리에 쿠키·세션·로컬스토리지가 저장되어 다음 실행 때 자동 복원된다.

```ts
// 변경 전
const browser = await chromium.launch({ headless: false });
const context = await browser.newContext();
const page = await context.newPage();

// 변경 후
const context = await chromium.launchPersistentContext('./.browser-profile', {
  headless: false,
});
const page = context.pages()[0] ?? (await context.newPage());
```

- 로그인 정보가 `./.browser-profile` 에 저장 → 재실행 시 재로그인 불필요
- 세션 만료 시: 로그인 페이지가 다시 뜨고, 사용자가 한 번 더 로그인하면 다시 저장된다. 아래 루프 구조가 이를 자연스럽게 흡수한다.
- 대안으로 `storageState`(JSON 한 파일) 방식이 있으나, 저장 타이밍을 코드로 관리해야 해 비개발자 사용자에게 부적합. persistent context 채택.

### 기능 B — 반복 루프

기존의 `collectLectures → for 루프 → 요약` 전체를 `while` 루프로 감싼다.

```
[실행] → launchPersistentContext (로그인 복원)
            │
            ▼
   ┌──────── while 루프 ────────┐
   │ "주차 이동 후 Enter (종료 q)" │
   │   Enter ▼      q → break    │
   │ collectLectures             │
   │ → 미완료 강의 for 루프 시청   │
   │ → 요약 출력 → 루프 위로 ↑    │
   └────────────────────────────┘
            │ (q 입력)
            ▼
   context.close()  → .browser-profile 에 로그인 잔존
```

- 입력 규약: **빈 Enter = 다음 배치 계속**, **`q` + Enter = 종료**
- 첫 회 안내문과 반복 회차 안내문을 구분한다.
  - 첫 회: "브라우저에서 로그인하고, 강의 목록(원하는 주차)으로 이동한 뒤 Enter"
  - 반복: "다음 주차로 이동 후 Enter (종료하려면 q + Enter)"
- 요약(`logger.summary`)은 매 배치마다 출력한다.

### 흐름 통합 (main.ts 의사코드)

```
const context = await chromium.launchPersistentContext('./.browser-profile', { headless: false });
const page = context.pages()[0] ?? await context.newPage();
if (config.startUrl !== 'about:blank') await page.goto(config.startUrl);

let first = true;
while (true) {
  안내문 출력 (first 여부에 따라 분기)
  const answer = (await rl.question(프롬프트)).trim().toLowerCase();
  if (!first && answer === 'q') break;   // 첫 회는 q여도 진행(로그인 대기 의미)
  first = false;

  const lectures = await collectLectures(page);
  const targets = lectures.filter((l) => l.status !== 'completed');
  ... 기존 for 루프 그대로 ...
  logger.summary(result);
}

await context.close();
```

> readline 인터페이스는 루프 바깥에서 한 번 생성하고, 루프 종료 후 `rl.close()`.

## 영향 범위

| 파일 | 변경 |
|------|------|
| `src/main.ts` | persistent context 전환 + while 루프. 핵심 변경. |
| `.gitignore` | `.browser-profile/` 추가 (로그인 쿠키 보관 폴더) |
| `README.md` | 종료 방법(q) 한 줄 + "프로필 폴더에 로그인 정보 저장되니 공유 금지" 주의 |

`collectLectures`, `runLecture`, `config.ts`, `logger.ts` 등 나머지 파일은 **건드리지 않는다**.

## 보안 / 주의

- `./.browser-profile` 에는 로그인 세션 쿠키가 평문에 가깝게 저장된다. 반드시 `.gitignore` 에 넣고, 타인과 폴더를 공유하지 않는다.
- 공용 PC에서는 사용 후 폴더를 삭제하면 로그인도 함께 제거된다(로그아웃 효과).

## 검증 기준

- [ ] 첫 실행 → 로그인 → 한 배치 시청 → Enter → 다른 주차 재수집·시청이 재로그인 없이 동작
- [ ] 한 배치 후 `q` 입력 시 정상 종료
- [ ] 프로그램 완전 종료 후 재실행 시 로그인 화면 없이 강의 목록 접근 가능
- [ ] `.browser-profile/` 이 git 추적에서 제외됨

## 비범위 (YAGNI)

- 자동 주차 이동(사람이 화면에서 이동) — 하지 않음
- 세션 만료 자동 감지/알림 — 하지 않음 (로그인 화면이 뜨면 사용자가 인지)
- storageState 병행 저장 — 하지 않음
