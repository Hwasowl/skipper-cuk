# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로.

> 강의 페이지에 들어가서 Enter 한 번만 누르면, 미완료 강의를 자동으로 끝까지 시청·출석 처리해줍니다.

---

## 사용 방법 (4단계)

### 1️⃣ Node.js 설치 (처음 한 번만)

[https://nodejs.org/ko/download](https://nodejs.org/ko/download) 에서 **LTS** 버전을 받아 설치합니다. (기본 옵션 그대로 "다음" 누르면 됨)

### 2️⃣ 이 프로젝트 다운로드

GitHub 페이지 우상단 초록색 **`<> Code`** → **Download ZIP** 클릭 → 압축 풀기.

### 3️⃣ 실행

압축 푼 폴더 안의 **`start.bat`** 더블클릭.

- **처음 실행 시:** 검은 창이 뜨면서 필요한 파일을 자동 다운로드합니다 (5~10분 정도). 다운로드 중에 인터넷 연결 필요.
- 완료되면 브라우저(Chromium)가 자동으로 가톨릭대 사이버캠퍼스 메인 페이지를 띄웁니다.

### 4️⃣ 브라우저에서 강의 페이지로 이동

브라우저에서:
1. 로그인
2. 수강 중인 과목 → **출석** 메뉴 → 원하는 **주차** 선택
3. 시청해야 할 강의 목록(1차시, 2차시...)이 보이는 상태로 둠

<img width="600" alt="강의 목록 화면" src="https://github.com/user-attachments/assets/a75b459b-524d-4a07-8760-034200820c0c" />

본인 인증(SMS 등)이 필요한 과목이면 이 단계에서 처리해주세요.

### 5️⃣ 검은 창(cmd)에 돌아와서 **Enter** 누르기

매크로가 페이지에 있는 강의들을 자동으로 인식하고 순차적으로 시청합니다:

- ✅ 이미 100% 완료된 강의 → 자동 스킵
- ▶️ 미완료/부분 시청 강의 → 자동 재생 후 출석 처리
- 다음 강의로 자동 이동

전부 끝나면 결과 요약이 표시됩니다.

---

## 다른 주차도 처리하려면?

브라우저에서 **다른 주차로 이동** → 검은 창에서 다시 `start.bat` 실행 → Enter.

---

## ⚠️ 주의사항

- **컴퓨터가 켜져 있어야 합니다.** 실시간으로 영상 길이만큼 기다리는 방식이라 강의 1개당 그 영상 길이만큼 시간이 걸립니다 (예: 42분 영상 → 약 43분 소요).
- 매크로 실행 중에는 **브라우저 창을 닫지 마세요**. 닫으면 매크로가 멈춥니다.
- 완료 후 브라우저는 자동으로 닫히지 않습니다. 결과 확인 후 직접 닫아주세요.
- 한 강의 처리 중 실패해도 다음 강의는 정상 진행됩니다.

## 자주 묻는 질문

**Q. 검은 창에서 `'npm'은(는) 내부 또는 외부 명령... 이 아닙니다`라고 뜹니다.**  
A. Node.js 설치가 안 됐거나 설치 후 컴퓨터를 재부팅하지 않은 경우입니다. 1단계 다시 확인 → 재부팅 → 재시도.

**Q. 60초 버퍼가 부족해요. 영상 끝나기 전에 종료 버튼이 눌립니다.**  
A. 폴더 안의 `.env.example`을 복사해 `.env` 라는 이름으로 저장한 뒤, 안의 `EXTRA_WAIT_SECONDS=60`을 더 큰 값(예: `120`)으로 바꾸세요.

**Q. 다른 주차도 한꺼번에 자동 처리하고 싶어요.**  
A. 현재는 한 번 실행 = 한 주차입니다. 주차별로 브라우저 이동 후 Enter를 다시 눌러주세요.
