# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로 (Playwright 기반).

## 요구사항

- Node.js 20+ (https://nodejs.org/ko/download)

## 설치

```bash
npm install
```

`postinstall` 훅이 자동으로 Chromium까지 받아놓습니다.

## 사용법

### 1. 매크로 실행

```bash
npm start
```

Chromium 창이 뜨면서 자동으로 가톨릭대 사이버캠퍼스 메인 페이지가 열립니다.

### 2. 강의 페이지로 이동

브라우저에서 직접 로그인 → 수강 중인 과목 → 출석 → 원하는 주차로 이동합니다.

화면에 1차시·2차시·3차시 등 강의 목록이 보이는 상태여야 합니다.

<img width="782" height="786" alt="image" src="https://github.com/user-attachments/assets/a75b459b-524d-4a07-8760-034200820c0c" />


### 3. 인증받기

학교 정책상 시청 전 본인 인증(휴대폰 SMS 등)을 요구하는 과목이 있으면 이 단계에서 처리합니다.

### 4. Enter로 자동 시청 시작

터미널(cmd)로 돌아와 **Enter** 키를 누릅니다.

매크로가 페이지의 강의 수만큼 자동 인식하고 순차적으로 처리:

- 이미 100% 완료된 강의는 자동 스킵
- 미완료/부분 시청 강의는 학습하기 클릭 → 재생 → `(영상 길이 - 이미 시청한 시간) + 60초` 대기 → 출석(종료) 클릭
- 강의 목록으로 돌아와 다음 강의로 진행

### 5. 다른 주차 반복

한 주차 완료 후 다른 주차도 처리하려면 **프로그램을 끄지 않고** 이어서 진행할 수 있습니다:
- 브라우저에서 다른 주차로 이동
- 터미널에서 **Enter** → 그 주차를 다시 인식해 자동 시청
- 끝내려면 터미널에 **q** 입력 후 Enter

> 로그인은 한 번만 하면 됩니다. 프로그램을 완전히 종료한 뒤 다시 `npm start` 해도 로그인이 유지되어 재인증이 필요 없습니다.

## 환경 변수 (선택)

`.env.example`을 `.env`로 복사해 값 수정.

| 변수 | 기본값 | 설명 |
|---|---|---|
| `START_URL` | `https://e-cyber.catholic.ac.kr/ilos/main/main_form.acl` | 브라우저 시작 URL |
| `END_BUTTON_DELAY_MS` | `3000` | 시청 완료 후 출석(종료) 버튼 클릭 전 버퍼(ms) |
| `PLAYER_READY_TIMEOUT_MS` | `30000` | 플레이어 페이지 로드 대기 타임아웃(ms) |
| `EXTRA_WAIT_SECONDS` | `60` | 영상 길이 외에 더 기다릴 시간(초) — 인트로/로딩 여유 |

## 동작 원리

비디오 element가 cross-origin iframe(cms.catholic.ac.kr) 안에 있어 `video.play()`·`video.ended` 같은 JS API 직접 호출은 불가합니다. Playwright `frameLocator`로 click 이벤트는 OS 레벨에서 디스패치되므로 cross-origin에서도 동작.

1. 강의 목록 페이지에서 각 카드의 진행률 텍스트(`0:00 / 42:43` + `0%`)를 파싱
2. 미완료 강의 큐 구성 (100% 완료된 항목은 자동 스킵)
3. 각 강의에 대해:
   - `학습하기` 클릭 → `#close_` 버튼 노출 대기 (플레이어 로드 확인)
   - iframe 안 `.vc-front-screen-play-btn` 클릭 (자동재생 안 되는 경우 대비)
   - `(duration - watched) + EXTRA_WAIT_SECONDS`만큼 실시간 대기, 30초마다 진행률 로그
   - `END_BUTTON_DELAY_MS` 추가 대기 후 `#close_` 클릭
   - 강의 목록 페이지로 복귀 대기

## 주의사항

- **로그인 정보는 `.browser-profile/` 폴더에 저장됩니다.** 이 폴더를 타인과 공유하지 마세요(로그인 세션이 들어 있습니다). 공용 PC에서는 사용 후 폴더를 삭제하면 로그아웃됩니다.
- q로 종료하면 브라우저가 함께 닫힙니다. 로그인은 폴더에 남아 다음 실행 때 재사용됩니다.
- 한 강의 처리 중 실패해도 다음 강의로 넘어갑니다. 끝에 요약 로그에서 실패 건수 확인.
- 실시간 대기 방식이므로 강의 1개당 영상 길이만큼 시간이 소요됩니다.
