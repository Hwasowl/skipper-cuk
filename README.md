# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로

## 요구사항

- Node.js 20+ (https://nodejs.org/ko/download)

## 가장 쉬운 실행 — start.bat 더블클릭 (비개발자용)

터미널 명령 없이 더블클릭만으로 실행합니다.

1. **Node.js 설치** — https://nodejs.org/ko/download 에서 LTS 버전을 받아 설치 (기본 옵션으로 "다음")
2. **이 프로젝트 다운로드** — GitHub 페이지 우상단 초록색 **`<> Code`** → **Download ZIP** → 압축 풀기
3. 압축 푼 폴더 안의 **`start.bat` 더블클릭**
   - 첫 실행 시 검은 창에서 필요한 파일을 자동 설치합니다 (5~10분, 인터넷 필요)
   - 설치가 끝나면 브라우저가 자동으로 열립니다

이후는 아래 [사용법](#사용법)의 강의 페이지 이동 → Enter 흐름과 같습니다.

> Node.js 설치 직후 start.bat이 "검은 창만 떴다 사라지면" 컴퓨터를 한 번 재시작한 뒤 다시 더블클릭하세요.

## 설치 (개발자용 — 직접 실행)

```bash
npm install
```

## 사용법

### 1. 매크로 실행
```bash
npm start
```

크롬 창이 자동으로 열리면서 가톨릭대 사이버캠퍼스 메인 페이지가 열립니다.

### 2. 로그인

크롬 창이 뜨면 **브라우저에서 직접 로그인**한 뒤, 터미널로 돌아와 **Enter**를 누릅니다.
(로그인은 한 번만 하면 됩니다. 이후 세션이 저장돼 재실행 시 유지됩니다.)

### 3. 자동 시청 (Todo 기반)

로그인 후 Enter를 누르면 매크로가 **메인페이지 Todo List의 첫 번째 `[온라인강의]` 항목**을
눌러 해당 주차 강의 목록 페이지로 이동합니다. 사람이 페이지를 옮길 필요가 없습니다.

강의 목록 페이지에 도달하면 그 페이지의 강의 수만큼 자동 인식해 순차 처리합니다:
- 이미 100% 완료된 강의는 자동 스킵
- 미완료/부분 시청 강의는 학습하기 클릭 → 재생 → `(영상 길이 - 이미 시청한 시간) + 60초` 대기 → 출석(종료) 클릭
- 강의 목록으로 돌아와 다음 강의로 진행
- 한 주차에 1·2·3차시가 함께 있으면 그 주차의 미완료분을 모두 처리

### 4. 반복 / 종료

한 주차가 끝나면 요약이 출력되고 프롬프트가 뜹니다:
- **Enter** — Todo를 다시 읽어 남은 첫 번째 온라인강의를 이어서 처리
- **`q` + Enter** — 종료 (로그인은 유지)

Todo에 남은 온라인강의가 없으면 자동으로 종료합니다.

> 세션 만료 등으로 로그인 화면이 다시 뜨면, 브라우저에서 로그인만 다시 하면 됩니다.

> 로그인은 한 번만 하면 됩니다. 프로그램을 완전히 종료한 뒤 다시 `npm start` 해도 로그인이 유지되어 재인증이 필요 없습니다.

## 실행 중 로그 예시

```
[1/3] 1차시 (42:43) — 시작
  → 시청 중... 0:30 / 42:43 (1%)
  → 시청 중... 1:00 / 42:43 (2%)
  ...
  → 영상 종료, 출석(종료) 클릭
[2/3] 2차시 (30:59) — 시작
  ...
[3/3] 3차시 (57:18) — 완료(100%), 스킵
────────────────────────────────────
완료: 2건 / 스킵: 1건 / 실패: 0건
소요 시간: 1h 25m 26s
────────────────────────────────────
```

## 주의사항

- **로그인 정보는 `.auth-state.json` 파일에 저장됩니다.** 이 파일을 타인과 공유하지 마세요(로그인 세션이 들어 있습니다). 공용 PC에서는 사용 후 파일을 삭제하면 로그아웃됩니다.
- q로 종료하면 브라우저가 함께 닫힙니다. 로그인은 폴더에 남아 다음 실행 때 재사용됩니다.
- 한 강의 처리 중 실패해도 다음 강의로 넘어갑니다. 끝에 요약 로그에서 실패 건수 확인.
- 실시간 대기 방식이므로 강의 1개당 영상 길이만큼 시간이 소요됩니다.
