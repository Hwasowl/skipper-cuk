# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로



https://github.com/user-attachments/assets/e178be7c-a138-420c-a5ca-519f920a9fdd




## 요구사항

- Node.js 20+ (https://nodejs.org/ko/download)

## 쉬운 시작

터미널 명령 없이 start.bat 파일로 실행합니다.

1. Node.js 설치: https://nodejs.org/ko/download 에서 LTS 버전을 받아 설치 (기본 옵션으로 "다음")
2. 이 프로젝트 다운로드:  GitHub 페이지 우상단 초록색 **`<> Code`** → **Download ZIP** → 압축 풀기
3. 압축 푼 폴더 안의 **`start.bat` 더블클릭**
   - 첫 실행 시 검은 창에서 필요한 파일을 자동 설치합니다 (1~3분, 인터넷 필요)
   - 설치가 끝나면 브라우저가 자동으로 열립니다

이후는 아래 [사용법](#사용법)의 강의 페이지 이동 → Enter 흐름과 같습니다.

## 사용법

### 1. 실행

start.bat 파일을 실행하면, 터미널창과 함께 크롬 창이 자동으로 열리면서 가톨릭대 사이버캠퍼스 메인 페이지가 열립니다.

### 2. 로그인하고 Enter

크롬 창이 뜨면 **브라우저에서 직접 로그인**한 뒤, 터미널로 돌아와 **Enter**를 누르면 시작됩니다.
이후로는 Todo List의 온라인강의를 자동으로 순서대로 시청하며, 다음 강의로 넘어갈 때도 Enter를 누를 필요가 없습니다.

- **인증 화면이 뜨면** 그 자리에서 인증만 하고 그대로 두세요. 자동으로 이어서 진행됩니다.
- 그만 보고 싶으면 터미널에 **`q` + Enter** — 처리 중인 강의는 마치고 종료합니다(로그인은 유지).
- 로그인은 한 번만 하면 됩니다. 세션이 저장돼 다음 실행부터는 재로그인이 필요 없습니다. 세션 만료로 로그인 화면이 다시 뜨면 그때만 다시 로그인하면 됩니다.

## 실행 중 로그 예시

```
[1/3] 1차시 (42:43) — 시작
  → 시청 중... 0:30 / 42:43 (1%)
  → 시청 중... 1:00 / 42:43 (2%)
  ...
  → 영상 종료, 출석(종료) 클릭
[2/3] 2차시 (30:59) — 시작
  ...
[3/3] 3차시 (57:18) — 완료(100%), 스킵
────────────────────────────────────
완료: 2건 / 스킵: 1건 / 실패: 0건
소요 시간: 1h 25m 26s
────────────────────────────────────
```

## 주의사항

- **로그인 정보는 `.auth-state.json` 파일에 저장됩니다.** 이 파일을 타인과 공유하지 마세요(로그인 세션이 들어 있습니다). 공용 PC에서는 사용 후 파일을 삭제하면 로그아웃됩니다.
- q로 종료하면 브라우저가 함께 닫힙니다. 로그인은 폴더에 남아 다음 실행 때 재사용됩니다.
- 한 강의 처리 중 실패해도 다음 강의로 넘어갑니다. 끝에 요약 로그에서 실패 건수 확인.
- 실시간 대기 방식이므로 강의 1개당 영상 길이만큼 시간이 소요됩니다.
