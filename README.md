# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로



https://github.com/user-attachments/assets/e178be7c-a138-420c-a5ca-519f920a9fdd




## 요구사항

- Node.js 20+ (https://nodejs.org/ko/download)

## 쉬운 시작

터미널 명령 없이 bat 파일로 실행합니다.

1. Node.js 설치: https://nodejs.org/ko/download 에서 LTS 버전을 받아 설치 (기본 옵션으로 "다음")
2. 이 프로젝트 다운로드:  GitHub 페이지 우상단 초록색 **`<> Code`** → **Download ZIP** → 압축 풀기
3. (선택) 압축 푼 폴더 안의 **`login.txt`** 를 메모장으로 열어 계정을 적고 저장 (아래 [계정 적기](#1-계정-적기-logintxt) 참고)
4. **`start-auto.bat` 더블클릭** (공유대학은 **`start-cu12-auto.bat`**)
   - 첫 실행 시 검은 창에서 필요한 파일을 자동 설치합니다 (1~3분, 인터넷 필요)
   - 설치가 끝나면 브라우저가 열리고, 계정을 적어뒀으면 자동으로 로그인합니다
   - 계정을 비워뒀으면 브라우저에서 직접 로그인한 뒤 터미널에 **Enter**를 누르세요

## 사용법

### 1. 계정 적기 (login.txt)

폴더 안의 `login.txt`를 메모장으로 열어 `=` 뒤에 적고 저장하세요. 사이트별로 칸이 나뉘어 있고, **모든 칸은 선택**입니다.
```
# [가톨릭대 사이버캠퍼스] (선택, 비워두면 브라우저에서 직접 로그인)
아이디=
비밀번호=

# [가톨릭공유대학 cu12] (선택, 비워두면 브라우저에서 직접 로그인)
공유대학아이디=
공유대학비밀번호=

# [구글 계정] (선택, 비워두면 2차 인증 창에서 직접 인증 — 아래 구글 계정 칸 채우기 참고)
구글계정=
구글앱비밀번호=
```
- 아이디·비밀번호를 **둘 다 비워두면** 브라우저에서 직접 로그인한 뒤 터미널에 Enter를 누르면 됩니다.
- **하나만 적혀 있으면** 메모장을 열어 둘 다 입력하라고 안내합니다. (직접 로그인하려면 둘 다 비우세요)
- `login.txt`에는 비밀번호가 그대로 저장됩니다. 다른 사람에게 보내지 말고, 공용 PC에서는 사용 후 삭제하세요.

#### 구글 계정 칸 채우기 (2차 인증 자동 입력, 선택)

강의를 열 때 뜨는 **2차 본인인증(이메일)** 을 자동으로 처리합니다. 인증메일을 받는 주소가 Gmail일 때만 됩니다.

**1) 구글 2단계 인증 켜기**

앱 비밀번호는 2단계 인증이 켜져 있어야 만들 수 있습니다. 이미 켜져 있으면 2)로 넘어가세요.

1. https://myaccount.google.com/security 접속 (인증메일을 받는 구글 계정으로 로그인)
2. **Google에 로그인하는 방법** 항목에서 **2단계 인증** 클릭
3. 안내에 따라 휴대폰 번호 등을 등록하고 **사용 설정**

**2) 앱 비밀번호 만들기**

1. https://myaccount.google.com/apppasswords 접속 (메뉴 안쪽에 숨어 있어 주소로 바로 들어가는 게 편합니다)
2. 앱 이름에 아무 이름(예: `skipper`)을 입력하고 **만들기**
3. 화면에 나온 **16자리**(예: `abcd efgh ijkl mnop`)를 복사합니다. 창을 닫으면 다시 볼 수 없으니 바로 붙여넣으세요. 잃어버리면 지우고 새로 만들면 됩니다.

**3) login.txt에 적기**

`login.txt`의 `[구글 계정]` 칸을 채우고 저장합니다.
```
구글계정=내주소@gmail.com
구글앱비밀번호=abcd efgh ijkl mnop
```
- 앱 비밀번호의 띄어쓰기는 있어도 없어도 됩니다.
- 이후 인증 창이 뜨면 이메일 인증을 눌러 Gmail에서 인증번호를 읽어 입력합니다. 2분 안에 메일이 안 오면 직접 인증하라고 안내합니다.
- 구글 계정 칸을 비워두면 지금처럼 인증 창에서 직접 인증할 때까지 기다렸다가, 인증이 끝나면 이어서 진행합니다.

**잘 안 될 때**

- **앱 비밀번호 페이지가 "사용할 수 없음"으로 나와요** → 2단계 인증이 꺼져 있거나, 학교·회사에서 관리하는 구글 계정입니다. 개인 Gmail(@gmail.com)을 쓰세요.
- **인증번호를 못 찾는다고 나와요** → 사이버캠퍼스 2차 인증에서 선택한 이메일이 `구글계정`과 같은 주소인지 확인하세요.

- 앱 비밀번호는 Gmail 전체를 읽을 수 있는 권한입니다. 다른 사람에게 보내지 말고, 그만 쓸 때는 앱 비밀번호 페이지에서 삭제하세요.

### 2. 가톨릭대 사이버캠퍼스 — `start-auto.bat`

실행하면 터미널창과 함께 크롬 창이 열리고, `login.txt`에 계정을 적어뒀으면 자동 로그인합니다(비워뒀으면 직접 로그인 후 Enter).
이후로는 Todo List의 온라인강의를 자동으로 순서대로 시청하며, 다음 강의로 넘어갈 때도 Enter를 누를 필요가 없습니다.

- **2차 인증 화면이 뜨면** 그 자리에서 인증만 하고 그대로 두세요. 자동으로 이어서 진행됩니다. (구글 계정을 적어두면 자동 인증 — 위 [구글 계정 칸 채우기](#구글-계정-칸-채우기-2차-인증-자동-입력-선택) 참고)
- 그만 보고 싶으면 터미널에 **`q` + Enter** — 처리 중인 강의는 마치고 종료합니다(로그인은 유지).
- 로그인 세션이 저장돼 다음 실행부터는 로그인 단계를 건너뜁니다.

### 3. 가톨릭공유대학(cu12) — `start-cu12-auto.bat`

1. 크롬 창에 공유대학(cu12.ac.kr) 메인 페이지가 열리고, `login.txt`에 공유대학 계정을 적어뒀으면 자동 로그인합니다(가톨릭대학교 선택, 비워뒀으면 직접 로그인 후 Enter).
2. 나의과정의 진행중 과정에서 미완료 차시를 자동으로 순서대로 시청합니다. 열린 강의를 모두 마치면 종료합니다(아직 열리지 않은 주차는 열린 뒤 다시 실행).

- 중간에 멈추려면 터미널에 **`q` + Enter**를 입력하세요.
- 로그인 세션은 `.auth-state-cu12.json`에 따로 저장됩니다. 사이버캠퍼스 세션과는 섞이지 않습니다.

```
  ...
  → 영상 종료, 출석(종료) 클릭
[2/3] 2차시 (30:59) — 시작
  ...

```

## 주의사항

- **로그인 정보는 `.auth-state.json`(공유대학은 `.auth-state-cu12.json`) 파일에 저장됩니다.** 이 파일을 타인과 공유하지 마세요(로그인 세션이 들어 있습니다). 공용 PC에서는 사용 후 파일을 삭제하면 로그아웃됩니다.
- q로 종료하면 브라우저가 함께 닫힙니다. 로그인은 폴더에 남아 다음 실행 때 재사용됩니다.
- 한 강의 처리 중 실패해도 다음 강의로 넘어갑니다. 끝에 요약 로그에서 실패 건수 확인.
- 실시간 대기 방식이므로 강의 1개당 영상 길이만큼 시간이 소요됩니다.
