# skipper-cuk

가톨릭대학교 사이버캠퍼스 강의 자동 수강 매크로

## 요구사항

- Node.js 20+ (https://nodejs.org/ko/download)

## 설치

```bash
npm install
```

## 사용법

### 1. 매크로 실행
```bash
npm start
```

크롬 창이 자동으로 열리면서 가톨릭대 사이버캠퍼스 메인 페이지가 열립니다.

### 2. 강의 페이지로 이동

브라우저에서 직접 로그인 → 수강 중인 과목 → 출석 → 원하는 주차로 이동합니다.
화면에 1차시·2차시·3차시 등 강의 목록이 보이는 상태여야 합니다.

### 3. 인증받기

- 학습하기 버튼을 눌러 인증을 진행해주세요. 
- 인증 완료 후 동영상 시청 페이지 이동될텐데, 이때 **강의 페이지(위 2번 이미지)** 로 다시 이동해주세요.

### 4. Enter로 자동 시청 시작

터미널(cmd)로 돌아와 **Enter** 키를 누릅니다.
매크로가 페이지의 강의 수만큼 자동 인식하고 순차적으로 처리합니다:
- 이미 100% 완료된 강의는 자동 스킵
- 미완료/부분 시청 강의는 학습하기 클릭 → 재생 → `(영상 길이 - 이미 시청한 시간) + 60초` 대기 → 출석(종료) 클릭
- 강의 목록으로 돌아와 다음 강의로 진행

### 5. 다른 주차 반복

한 주차 완료 후 다른 주차도 처리하려면 같은 흐름을 반복:
- 브라우저에서 다른 주차로 이동
- 터미널에서 다시 `npm start` 실행 → Enter

```
  ...
  → 영상 종료, 출석(종료) 클릭
[2/3] 2차시 (30:59) — 시작
  ...

────────────────────────────────────
완료: 2건 / 스킵: 1건 / 실패: 0건
소요 시간: 1h 25m 26s

```

## 주의사항

- 매크로 종료 후 브라우저는 자동으로 닫히지 않습니다 (사용자가 결과 확인 가능). 직접 닫아주세요.
- 한 강의 처리 중 실패해도 다음 강의로 넘어갑니다. 끝에 요약 로그에서 실패 건수 확인.
- 실시간 대기 방식이므로 강의 1개당 영상 길이만큼 시간이 소요됩니다.
